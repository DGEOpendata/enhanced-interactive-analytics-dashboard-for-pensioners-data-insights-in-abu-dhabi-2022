# Enhanced Interactive Analytics Dashboard for Pensioners Data Insights in Abu Dhabi 2022

This repository contains the code and resources needed to deploy an interactive dashboard for exploring the "Pensioners Distribution Data for 2022" dataset. The dashboard provides dynamic visualizations and insights into the demographic distribution of pensioners in Abu Dhabi for 2022.

## Features
- **Interactive Visualizations**: Bar charts, pie charts, and line graphs to explore gender distribution and quarterly trends.
- **Drill-Down Capabilities**: Filter data based on selected criteria such as gender and quarter.
- **Downloadable Reports**: Generate and download tailored reports and visualizations.
- **Predictive Analytics**: Forecast demographic trends based on historical data.

## Requirements
- Python 3.8+
- Dash
- Plotly
- Pandas
- OpenPyXL

## Installation
1. Clone the repository:
   bash
   git clone https://github.com/your-repo-url/abu-dhabi-pension-dashboard.git
   cd abu-dhabi-pension-dashboard
   
2. Install the required Python packages:
   bash
   pip install dash plotly pandas openpyxl
   
3. Ensure the dataset `Distribution_of_Pensioners_2022.xlsx` is in the same directory.

## Running the Dashboard
1. Execute the script:
   bash
   python app.py
   
2. Open your browser and navigate to `http://127.0.0.1:8050/`.
3. Interact with the dashboard to explore pensioner data for Abu Dhabi in 2022.

## How to Use
- Use the dropdown menu to filter the data by specific quarters.
- Analyze gender distribution via bar charts.
- View trends in the total number of pensioners across quarters using line graphs.
- Export visualizations as images or download tailored reports for further analysis.
